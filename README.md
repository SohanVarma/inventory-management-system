# Inventory Management For Small Businesses

## Features
- Admin/Staff login
- Role-based access
- Product management
- Supplier management
- Sales history
- Low-stock alerts
- Dashboard analytics
- Business analytics graphs
  - Revenue trend
  - Stock by branch
  - Top selling products
  - Category-wise stock
  - Sales by branch
  - Low-stock product chart
- Barcode/SKU lookup
- Camera barcode scanner
- Branch-wise stock tracking
- Colorful responsive UI
- Local JSON database integration through `server/database.json`

## Run Server
```bash
cd server
npm install
npm run dev
```

## Run Client
```bash
cd client
npm install
npm run dev
```

## Login
Admin: `admin / admin123`

Staff: `staff / staff123`
